# openapi-spec-validator-rs

A fast, drop-in Rust companion to [openapi-spec-validator](https://github.com/python-openapi/openapi-spec-validator).

It validates Swagger 2.0 and OpenAPI 3.0, 3.1 and 3.2 documents using the same rules as the Python
implementation, and aims to return the same verdicts.

> **Status:** under active development; not yet released.
